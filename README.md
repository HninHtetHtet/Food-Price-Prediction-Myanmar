# Food Price in Myanmar

A data analysis project examining food prices in Myanmar, utilizing Python for data processing/analysis and Tableau for visualization.

## Project Overview
This project aims to analyze the trends, fluctuations, and patterns of food prices in Myanmar. By combining Python's powerful data manipulation capabilities with Tableau's interactive dashboards (`.twb` and `.hyper`), this repository provides clear insights into market dynamics and food economics.

## Technologies Used
* **Python** (Data Processing, Cleaning, and Analysis)
* **Tableau** (Interactive Data Visualization, Dashboard Design - `.twb` / `.hyper`)
